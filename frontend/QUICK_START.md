# 🚀 Быстрый старт - Тестирование ECIES

## Вариант 1: Тестирование в браузере (рекомендуется)

1. **Откройте файл в браузере:**
   ```bash
   open frontend/test-encryption.html
   ```

2. **Нажмите "Запустить тест"**

3. **Проверьте результаты в консоли**

## Вариант 2: Тестирование в Node.js

1. **Установите зависимости:**
   ```bash
   cd frontend
   npm install
   ```

2. **Запустите тест:**
   ```bash
   npm test
   ```


## ✅ Если тест прошел успешно

Этап 1 завершен! Можно переходить к Этапу 2: Генерация ключей из SEED.

## ❌ Если тест не прошел

1. Проверьте консоль браузера на ошибки
2. Убедитесь, что библиотеки загружены
3. Проверьте интернет-соединение для CDN

# План обновления смарт-контракта для двойного шифрования, для версии V2

## 🎯 Цель
Реализовать двойное шифрование сообщений для обеспечения возможности восстановления исходящих сообщений на новом устройстве.

## 📋 Требуемые изменения

### 1. Обновление структуры данных

#### Текущая структура:
```solidity
event MessageSent(
    address indexed sender,
    address indexed recipient,
    bytes encryptedMessage
);
```

#### Новая структура:
```solidity
struct MessageData {
    address recipient;
    bytes encryptedForRecipient;
    bytes encryptedForSender;
}

event MessageSent(
    address indexed sender,
    address indexed recipient,
    bytes encryptedForRecipient,
    bytes encryptedForSender
);
```

### 2. Обновление функции sendMessage

#### Текущая функция:
```solidity
function sendMessage(address recipient, bytes calldata encryptedMessage) external
```

#### Новая функция:
```solidity
function sendMessage(
    address recipient, 
    bytes calldata encryptedForRecipient,
    bytes calldata encryptedForSender
) external
```

### 3. Обновление модификаторов и проверок
- Добавить проверку длины зашифрованных данных
- Обновить gas estimation
- Добавить валидацию структуры данных

## ⚠️ Важные моменты

### Совместимость
- Новый контракт должен быть совместим с существующими данными
- Возможно потребуется миграция данных

- Нужно пересчитать gas limits
- Возможно потребуется оптимизация

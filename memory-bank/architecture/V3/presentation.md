# Web3shold - Презентация проекта

## 🎯 **Что это такое?**

**Web3shold** - полностью децентрализованный мессенджер на блокчейне. Каждое сообщение зашифровано локально и хранится в распределенной сети без единого сервера.

### 📛 **Значение названия:**
1. **Web3 + shold** → «Web3 должен» (should) - предназначение Web3 реализоваться
2. **Web + Threshold** → «Порог к Web3» - переход к новому уровню приватности

---

## 🔐 **Ключевые преимущества:**

### **🛡️ БЕЗОПАСНОСТЬ И ПРИВАТНОСТЬ**
- **Сквозное шифрование ECIES** - только участники читают сообщения
- **Локальные ключи** - генерируются из подписи MetaMask, не передаются в сеть
- **Двойное шифрование** - для получателя И для себя (восстановление исходящих)
- **Авторизация без данных** - без телефона/email, имя необязательно

### **🌐 ДЕЦЕНТРАЛИЗАЦИЯ**
- **Работает на блокчейне** - Base, Polygon, легко расширяется
- **Устойчивость к цензуре** - нет единой точки отказа
- **Истинное владение данными** - пользователь контролирует всё своим SEED

### **📱 СОВРЕМЕННЫЙ UX**
- **PWA приложение** - устанавливается как нативное
- **Адаптивный дизайн** - телефоны и десктопы
- **Один клик подключения** - через MetaMask/RabbyWallet
- **Автосинхронизация** - сообщения появляются сами (15 сек)
- **Интуитивные статусы** - 🚫📥⏳ для состояния чата

### **💰 ЭКОНОМИЧНОСТЬ**
- **Спам-защита** - платная отправка, дорогие первые сообщения
- **Оптимизированный газ** - кастомные ошибки, батчинг данных
- **Кэширование** - минимум обращений к блокчейну

## 🚀 **Конкурентные преимущества:**

### **VS Centralized (Telegram/WhatsApp):**
- **Невозможно заблокировать** - нет центрального сервера
- **Открытый код** - полная прозрачность
- **Владение данными** - контроль через SEED

### **VS Web3 мессенджеры (XMTP, Status):**
- **Полная автономность** - не зависит от протоколов третьих лиц  
- **Production ready** - полнофункциональное приложение
- **Простая архитектура** - понятная и расширяемая

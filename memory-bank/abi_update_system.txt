# Система обновления ABI

## Обзор
Создана надежная система обновления ABI контракта в config.js с тремя уровнями fallback.

## Файлы системы
- `abi-raw.json` - основной источник ABI (ручное копирование с Basescan)
- `scripts/update-abi.js` - скрипт форматирования и обновления
- `frontend/config.js` - целевой файл с отформатированным ABI

## Приоритет источников ABI
1. **abi-raw.json** - основной источник (надежный)
2. **Basescan API** - резервный источник (требует API ключ)
3. **Локальный контракт** - fallback (out/CryptoMessenger.sol/CryptoMessenger.json)

## Инструкция по использованию

### Шаг 1: Получение ABI
1. Откройте https://basescan.org/address/0xc8F47D1A4018D3e4Df136832d42c479A2C5eB4df#code
2. Найдите раздел "Contract ABI"
3. Скопируйте весь JSON массив ABI

### Шаг 2: Обновление abi-raw.json
1. Откройте файл `abi-raw.json`
2. Вставьте скопированный ABI (замените содержимое)
3. Сохраните файл

### Шаг 3: Запуск обновления
```bash
make update-abi
# или
node scripts/update-abi.js
```

## Преимущества системы
- ✅ Надежность - не зависит от API доступности
- ✅ Скорость - локальное чтение файла
- ✅ Контроль - полный контроль над ABI
- ✅ Fallback - несколько уровней резерва
- ✅ Форматирование - автоматическое красивое форматирование

## Структура abi-raw.json
```json
[
  {
    "type": "constructor",
    "inputs": [],
    "stateMutability": "nonpayable"
  },
  {
    "type": "function",
    "name": "registerPublicKey",
    "inputs": [
      {
        "name": "_user_public_key",
        "type": "bytes",
        "internalType": "bytes"
      }
    ],
    "outputs": [],
    "stateMutability": "nonpayable"
  }
  // ... остальные функции и события
]
```

## Автоматизация
Скрипт автоматически:
- Парсит JSON из abi-raw.json
- Форматирует ABI с отступами
- Обновляет contractABI в config.js
- Обновляет версию и дату в console.log
- Показывает статистику (функции/события)

# Оптимизация структуры проекта
## Дата: 2025-01-13 00:25

### 🎯 Проблема
- Папки `cache` и `broadcast` создавались в корне проекта
- Нарушалась чистота структуры проекта
- Все файлы, связанные с контрактами, должны быть в папке `contracts/`

### ✅ Решение
Обновлен `foundry.toml` с правильными настройками:

```toml
[profile.default]
src = "contracts"
test = "contracts/test"
out = "contracts/out"
libs = ["contracts/lib"]
solc = "0.8.19"
optimizer = true
optimizer_runs = 200
via_ir = false
verbosity = 2

# Cache and broadcast directories
cache_path = "contracts/cache"
broadcast = "contracts/broadcast"
```

### 📁 Текущая структура проекта


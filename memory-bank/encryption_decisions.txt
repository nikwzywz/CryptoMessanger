# Решения по шифрованию CryptoMessenger

## Архитектура шифрования

### Разделение ответственности
- **MetaMask/Rabby Wallet:** Только для блокчейн операций
  - Получение зашифрованных сообщений из блокчейна
  - Отправка новых зашифрованных сообщений в блокчейн
  - Подписание транзакций

- **Приложение:** Шифрование/расшифровка
  - Генерация ключей из SEED фразы
  - Шифрование сообщений перед отправкой
  - Расшифровка полученных сообщений

### SEED фраза для шифрования
- **Отдельная SEED фраза** от кошелька
- Пользователь вводит SEED в приложении
- Из SEED генерируются ключи для шифрования
- SEED хранится только локально в приложении

## Техническая реализация

### Алгоритм шифрования
- **RSA + AES** (гибридный подход)
- RSA 4096 бит для шифрования симметричного ключа
- AES 256 бит для шифрования сообщения
- Режим AES: CBC

### Процесс шифрования
1. Генерация случайного AES ключа
2. Шифрование сообщения AES ключом
3. Шифрование AES ключа публичным ключом получателя (RSA)
4. Отправка зашифрованных данных в блокчейн

### Процесс расшифровки
1. Получение зашифрованных данных из блокчейна
2. Расшифровка AES ключа приватным ключом получателя (RSA)
3. Расшифровка сообщения AES ключом

### Библиотеки
- **Web Crypto API** (приоритет)
- **crypto-js** (fallback)
- **node-forge** (для Node.js)

### Формат данных
```javascript
{
  encryptedMessage: "base64_encrypted_data",
  encryptedKey: "base64_encrypted_aes_key",
  iv: "base64_initialization_vector",
  algorithm: "RSA-OAEP",
  keySize: 4096
}
```

## Безопасность

### Преимущества подхода
- MetaMask не имеет доступа к ключам шифрования
- SEED фраза хранится только локально
- Шифрование происходит в браузере пользователя
- Полная децентрализованность

### Риски и меры
- **Потеря SEED фразы** = потеря доступа к сообщениям
- **Компрометация устройства** = доступ к сообщениям
- **Меры:** Шифрование локального хранилища, возможность экспорта ключей

## Конфигурация

```javascript
const ENCRYPTION_CONFIG = {
  rsaKeySize: 4096,
  aesKeySize: 256,
  aesMode: 'CBC',
  encoding: 'base64',
  compression: 'after', // gzip после шифрования
  signature: false,     // Пока не нужно
  seedDerivation: 'PBKDF2' // Производная ключей из SEED
};
```

## Вопросы решены
✅ Алгоритм шифрования: RSA + AES  
✅ Размер ключей: RSA 4096, AES 256  
✅ Библиотека: Web Crypto API + crypto-js  
✅ Формат данных: Base64  
✅ Сжатие: gzip после шифрования  
✅ Подпись: Пока не нужна  
✅ Управление ключами: Отдельная SEED фраза

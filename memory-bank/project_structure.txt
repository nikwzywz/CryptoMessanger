# Структура проекта CryptoMessenger
## Дата: 2025-01-12 21:30

## 🏗️ ОБЩАЯ АРХИТЕКТУРА

Проект разделен на две основные части:
- **contracts/** - блокчейн часть (смарт-контракты, тесты, деплой)
- **pwa/** - веб-приложение (фронтенд, скрипты, расширения)

## 📁 ДЕТАЛЬНАЯ СТРУКТУРА

```
CryptoMessanger/
├── contracts/                    # Блокчейн часть
│   ├── CryptoMessenger.sol      # Основной контракт
│   ├── interfaces/              # Интерфейсы контрактов
│   ├── script/                  # Скрипты деплоя
│   │   └── Deploy.s.sol
│   ├── test/                    # Тесты Foundry
│   │   └── CryptoMessenger.t.sol
│   ├── lib/                     # Библиотеки Foundry
│   │   └── forge-std/
│   ├── out/                     # Артефакты компиляции
│   ├── cache/                   # Кэш Foundry
│   └── broadcast/               # Результаты деплоя
├── pwa/                         # Веб-приложение (PWA)
│   ├── frontend/                # Фронтенд
│   │   ├── auth-v2.html         # Авторизация через MetaMask
│   │   ├── main.html            # Главная страница мессенджера
│   │   ├── config.js            # Централизованная конфигурация
│   │   └── lib/                 # JavaScript библиотеки
│   ├── scripts/                 # Скрипты автоматизации
│   │   ├── update-abi.js        # Обновление ABI
│   │   └── populate-contract-test-data.js  # Тестовые данные
│   └── chrome-extension/        # Расширение браузера
├── memory-bank/                 # Документация проекта
├── abi-raw.json                 # ABI контракта (для обновления)
├── foundry.toml                 # Конфигурация Foundry
├── Makefile                     # Команды автоматизации
└── .env                         # Переменные окружения
```

## 📋 ПРЕИМУЩЕСТВА НОВОЙ СТРУКТУРЫ

### 1. Четкое разделение ответственности
- **contracts/** - все, что связано с блокчейном
- **pwa/** - все, что связано с веб-приложением

### 2. Улучшенная организация
- Логическое группирование файлов
- Упрощенная навигация по проекту
- Четкие границы между компонентами

### 3. Масштабируемость
- Легко добавлять новые контракты в `contracts/`
- Легко добавлять новые страницы в `pwa/frontend/`
- Возможность отдельного деплоя компонентов

### 4. Совместимость с инструментами
- Foundry работает с `contracts/`
- Веб-сервер работает с `pwa/frontend/`
- CI/CD может работать с отдельными частями

## 🚀 КОМАНДЫ ДЛЯ РАБОТЫ

### Разработка контрактов
```bash
cd contracts/
forge build
forge test
forge script script/Deploy.s.sol --rpc-url base --broadcast
```

### Разработка фронтенда
```bash
cd pwa/frontend/
python3 -m http.server 8081
```

### Обновление ABI
```bash
make update-abi
# или
node pwa/scripts/update-abi.js
```

### Заполнение тестовыми данными
```bash
make populate-contract
# или
node pwa/scripts/populate-contract-test-data.js
```

### 🛠️ Технические детали

#### Файлы для создания:
- `frontend/main.html` - главная страница мессенджера
- `frontend/lib/ecies.js` - библиотека шифрования
- `frontend/lib/message-handler.js` - обработка сообщений
- `frontend/lib/contact-manager.js` - управление контактами

#### Интеграции:
- Web3 для работы с контрактом
- ECIES для шифрования
- LocalStorage для кэширования
- WebSocket для real-time обновлений (опционально)

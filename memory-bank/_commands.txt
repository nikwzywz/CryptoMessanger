
# Команды проекта CryptoMessenger

## Разработка
make build                  - компиляция
make test                   - тестирование (18/18 тестов проходят)
make deploy-base            - развертывание в Base Mainnet
make deploy-sepolia         - развертывание в Base Sepolia
make deploy-local           - локальное развертывание
make clean                  - очистка артефактов

## Frontend
cd frontend && python3 -m http.server 8080  - запуск локального сервера
open http://localhost:8080/auth.html        - страница авторизации
open http://localhost:8080/regpub.html      - регистрация ключа

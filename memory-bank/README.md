# CryptoMessenger - Memory Bank

## 📋 Обзор проекта

CryptoMessenger - это децентрализованный мессенджер, работающий на блокчейне Base. Пользователи могут отправлять зашифрованные сообщения напрямую друг другу без централизованных серверов.

## 🏗️ Архитектура

- **Смарт-контракт**: Solidity контракт на Base Mainnet
- **Шифрование**: ECIES с secp256k1 ключами
- **Frontend**: PWA с децентрализованной системой событий
- **Сеть**: Base (дешевые транзакции)

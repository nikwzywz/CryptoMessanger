# MVP Требования CryptoMessanger

## Основной функционал
1. **Подключение кошелька** (MetaMask/Rabby Wallet)
2. **Регистрация публичного ключа** при первом входе
3. **Запрос на добавление в контакты** с дополнительной платой (~$10)
4. **Принятие/отклонение запросов** на добавление в контакты
5. **Отправка зашифрованных сообщений** только пользователям из белого списка
6. **Получение и расшифровка сообщений**
7. **Локальное хранение истории** всех сообщений
8. **PWA уведомления** о новых сообщениях

## Технические требования
- **Сеть:** Base (дешевые транзакции)
- **Сжатие:** gzip для сообщений > 500 байт
- **Шифрование:** End-to-end на клиенте
- **Хранение:** Events в блокчейне + локальное кэширование
- **Интерфейс:** PWA приложение

## Смарт-контракт методы
```solidity
// Регистрация публичного ключа
function registerPublicKey(bytes memory publicKey) external

// Запрос на добавление в контакты
function requestContact(address to, bytes memory firstMessage, bytes memory encryptedData) external payable

// Принятие запроса
function acceptContactRequest(address from) external

// Отклонение запроса (средства не возвращаются)
function rejectContactRequest(address from) external

// Отправка сообщения (только в белый список)
function sendMessage(address to, bytes memory encryptedData) external

// Получение публичного ключа
function getPublicKey(address user) external view returns (bytes memory)

// Проверка статуса контакта
function isContact(address user, address contact) external view returns (bool)
```

## События (Events)
```solidity
event PublicKeyRegistered(address indexed user, bytes publicKey);
event ContactRequested(address indexed from, address indexed to, bytes firstMessage, uint256 payment);
event ContactAccepted(address indexed from, address indexed to);
event ContactRejected(address indexed from, address indexed to);
event MessageSent(address indexed from, address indexed to, bytes encryptedData, uint256 timestamp);
```

## Frontend компоненты
1. **WalletConnection** - подключение кошелька
2. **KeyRegistration** - регистрация публичного ключа
3. **ContactRequests** - управление запросами на добавление
4. **ChatList** - список чатов
5. **ChatWindow** - окно чата с сообщениями
6. **MessageInput** - ввод и отправка сообщений
7. **Notifications** - PWA уведомления

## НЕ входит в MVP
- Групповые чаты
- Rate limiting
- Экспорт истории
- Валидация контента
- Мультиаккаунт (поддерживается кошельками)

# Логика работы интерфейса приложения CryptoMessenger

## Обзор системы панелей (компонентов, из которых состоит интерфейс главной формы CryptoMessenger)

Интерфейс CryptoMessenger динамически изменяется в зависимости от статуса чата между пользователями. Вместо статичного поля ввода сообщений используется система адаптивных панелей.

### 1. Панель "Область ввода и отправки сообщений"
**Название** panelInputAndSendMessage
**Условие показа:** Состояние == allowedWrite
**Из чего состоит**
- Показывается поле "Введите сообщение..."
- Кнопка отправки активна
- Пользователь может свободно писать и отправлять сообщения
**Особенность** если не выбран никакой чат, то показывается одно сообщение: "Добро пожаловать в CryptoMessenger! Выберите контакт для начала общения."
**Реализация** Завести функцию с одним аргументом setVisiblePanelInputAndSendMessage(bool visible)

### 2. Панель "ВХОДЯЩЕЕ ПРИГЛАШЕНИЕ"
**Название** panelWaitingAcceptanceFromMe
**Условие показа:** Состояние == waitingAcceptanceFromMe
**Интерфейс:**
- Панель "Приглашение в контакты"
- Адрес отправителя: "От: <адрес отправителя>"
- Кнопка "Разрешить общение" (зелёная)
- Кнопка "Запретить" (красная)
**Реализация** Завести функцию с одним аргументом setVisiblePanelWaitingAcceptanceFromMe(bool visible)

### 3. Панель "ИСХОДЯЩЕЕ ПРИГЛАШЕНИЕ"
**Название** panelWaitingAcceptanceFromOther
**Условие показа:** Состояние == waitingAcceptanceFromOther
**Интерфейс:**
- ⏳ Панель "Ожидание принятия приглашения"
- 🔄 Анимированная иконка ожидания (пульсирует)
- 📍 Адрес получателя: "Кому: 0x..."
- 💬 Сообщение "Пользователь ещё не ответил на ваше приглашение"
**Особенность** если прошло времени менее чем INVITATION_TIMEOUT с момента отправки приглашения, 
- то показывать "Через HH часов вы сможете отменить ваше приглашение"
- иначе показывать кнопку "Отозвать приглашение" (и под ней приписка "и вернуть себе комиссию")
**Реализация** Завести функцию с одним аргументом setVisiblePanelWaitingAcceptanceFromOther(bool visible)


## Карточка контакта в списке контактов содержит поля:
- Имя контакта (если имя пустое, то отображать адрес контакта)
  Эти данные обрезать по ширине поля
- Под именем расположить область для отображения начала последнего сообщения.
- Справа отображать Визуальные индикаторы списка контактов (описано ниже).

## Визуальные индикаторы в списке контактов

**Входящее приглашение:**
- На месте количества непрочитанных сообщений - Красный бейдж "!" 

**Исходящее приглашение:**
- На месте количества непрочитанных сообщений - Жёлтый бейдж "!" 

**Иначе, Обычный контакт:**
- Бейдж с количеством непрочитанных (если есть)

## Мобильная адаптивность

На экранах шириной ≤768px:
- Кнопки располагаются вертикально
- Уменьшенные отступы и размеры иконок
- Панели занимают всю ширину экрана
- Поддержка системной кнопки "назад" Android

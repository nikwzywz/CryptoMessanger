# Функциональность приглашений в CryptoMessenger v2

## ✅ Добавленные возможности

### 1. UI для работы с приглашениями
- **Кнопка "Отправить приглашение"** в боковой панели
- **Кнопка "Обновить приглашения"** для синхронизации
- **Модальные окна** для отправки и обработки приглашений
- **Кнопки действий** для каждого типа приглашений

### 2. Отправка приглашений
```javascript
await sendInvitation(recipientAddress, message, fee)
```
- Валидация адреса получателя
- Шифрование сообщения для обеих сторон
- Отправка с указанной комиссией
- Автоматическое обновление интерфейса

### 3. Принятие приглашений
```javascript
await acceptInvitation(inviterAddress)
```
- Активация чата
- Возврат денег отправителю
- Добавление в список контактов

### 4. Отклонение приглашений
```javascript
await rejectInvitation(inviterAddress)
```
- Деактивация чата
- Возврат денег получателю
- Уведомление об отклонении

### 5. Отзыв приглашений
```javascript
await cancelInvitation(recipientAddress)
```
- Отзыв через 3 дня (таймаут)
- Возврат денег отправителю
- Деактивация чата

## 🎨 Интерфейс

### Модальное окно отправки приглашения
- Поле для адреса получателя
- Текстовое поле для сообщения
- Поле для указания комиссии
- Кнопки "Отправить" и "Отмена"

### Модальное окно обработки приглашений
- Информация о приглашении
- Кнопки "Принять", "Отклонить", "Отмена"
- Отображение отправителя и комиссии

### Кнопки действий в списке контактов
- **Входящие приглашения**: ✅ Принять, ❌ Отклонить
- **Исходящие приглашения**: 🔄 Отозвать
- **Обычные контакты**: без дополнительных кнопок

## 🔧 Технические детали

### Интеграция с контрактом v2
- Использование `invitationSend()` вместо `requestContact()`
- Использование `invitationAccept()` вместо `acceptContactRequest()`
- Использование `invitationReject()` вместо `rejectContactRequest()`
- Новая функция `invitationCancel()` для отзыва

### Шифрование
- Двойное шифрование для отправителя и получателя
- Использование публичных ключей из контракта
- Поддержка простого hex-шифрования для тестирования

### Обработка ошибок
- Валидация адресов
- Проверка заполненности полей
- Обработка ошибок блокчейна
- Уведомления пользователя

## 📋 Использование

### Для отправки приглашения:
1. Нажать кнопку "📤 Отправить приглашение"
2. Ввести адрес получателя
3. Написать сообщение приглашения
4. Указать комиссию (по умолчанию 0.00000217 ETH)
5. Нажать "Отправить приглашение"

### Для обработки входящих приглашений:
1. Найти приглашение в списке контактов (с зеленой полосой)
2. Нажать ✅ для принятия или ❌ для отклонения
3. Подтвердить действие

### Для отзыва исходящих приглашений:
1. Найти исходящее приглашение в списке (с желтой полосой)
2. Нажать 🔄 для отзыва
3. Подтвердить действие
